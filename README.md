# Green API Chat

Веб-клиент для мессенджера на базе [Green API](https://green-api.com/). Позволяет подключиться к своему инстансу, просматривать чаты и переписываться в реальном времени.

## Стек

- React + TypeScript
- Vite
- MobX
- Tailwind CSS
- Axios
- React Router

## Требования

- Node.js 18+
- npm 9+

## Запуск локально

### 1. Клонировать репозиторий

```bash
git clone <url-репозитория>
cd <папка-проекта>
```

### 2. Запуск приложения 

```bash
npm install
npm run dev
```
